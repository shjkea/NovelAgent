# 题材词模板（Genre word template）

## 为什么提示词里用的是中性词

公开发布的提示词默认使用**中性泛化词**（例如「超自然」「日常」「能力等级」），
而不是具体题材词。这样做的目的是：公开仓库时不暴露
作者的具体写作方向，也避免把某一类题材的措辞硬编码进通用流程。

## 如何替换回你自己的题材

如果你的作品是特定题材，希望系统在规划、生成和审查时使用对应措辞，可以把提示词里的
中性词替换成下表右列的题材词。用全局搜索替换即可。

| 中性词（当前默认） | 可替换为（按你的题材） |
| --- | --- |
| 超自然 | 修炼、超凡、异能、灵异、修仙 |
| 日常生活 / 日常细节 / 日常陪伴 | 校园、都市、职场、家庭 |
| 能力等级 | 修为、等级、段位、境界 |
| 能力 | 功法、技能、法术、异能 |
| 成长进度 | 境界、段位、等级 |

## 替换位置

这些词主要出现在以下文件的内嵌提示词中：

- `agent_core.py`：章节规划、正文生成、审稿、纠偏重写、审计修复等各阶段提示词
- `canon_guard.py`：知识边界正则（原「功法」已移除）

## 人物标签

人物设定解析使用的标题标签在 `agent_core.py` 的 `stop` 集合里（如「主角」「配角」
「NPC」「其他人物」）。如需自定义，可自行增删，保持与 `story/characters_seed.md` 的
标题一致即可。

## 注意

- 这些提示词只影响生成时的措辞与约束，不影响程序功能。
- 替换后建议先跑 `python -m pytest -q` 确认没有破坏语法或逻辑。
