# DLC expansion reference

This file contains optional guidance for non-canonical scene expansion. Replace
or extend it with project-specific material that is safe to send to your chosen
model provider.

## Continuity

- Preserve the people, location, time, objects, and knowledge state at the marker.
- Any state change needs a visible cause and a feasible transition.
- Do not turn an optional scene into a new canonical fact.

## Style

- Match the chapter's viewpoint, tense, paragraph rhythm, and dialogue style.
- Avoid repeated sentences, repeated reactions, and summary-style narration.
- Return only the prose that should be inserted at the marker.

## Safety

- Do not include secrets, credentials, personal data, or private source material.
- Follow the selected model provider's acceptable-use policy.
